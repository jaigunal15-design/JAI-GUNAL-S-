Scene 01The story so far

I'm Jai, a first-year B.Tech student in Information Technology. I chose this course because I wanted to understand the things I use every single day: how a page appears when I tap a link, how an app knows what I just pressed.

Right now I'm at the stage where every small win feels loud. A program that runs on the first try. A layout that finally lines up. A bug I fixed without asking anyone. I'm not trying to rush past that stage; I'd rather learn the basics properly and enjoy it.

I like getting details right more than getting things done fast. That is why this site looks like the opening of a film: every project I'll ever make starts as a blank screen and a title, and I wanted mine to start with some care.

Slow and careful now, so I can be fast and sure later.
